MOLSOM LANGUAGE INSTITUTE WEBSITE
=================================

Files
- index.html: responsive professional website. Open it in a browser to preview.

Included features
- Responsive navigation and landing page
- Program cards and lesson pop-ups
- Writing notebook saved in this browser
- Vocabulary builder with add/delete
- Export vocabulary as JSON
- No invented Molsom translations: add examples verified by a fluent speaker or teacher

How to use
1. Extract the ZIP file.
2. Open index.html in Chrome, Edge, Firefox or another modern browser.
3. To edit the institute's contact information, open index.html in VS Code and find the Contact the institute button handler near the end of the file.
4. To publish free, upload index.html to a GitHub repository and enable GitHub Pages in Settings > Pages.

Important
The notebook and vocabulary list use local browser storage on the current device/browser; they are not synced to a server. This is a front-end starter site. A real student login, teacher dashboard, online database, payments, and contact form delivery require a backend or external service.
